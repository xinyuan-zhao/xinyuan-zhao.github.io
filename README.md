# Xinyuan (Skyla) Zhao — Portfolio

Personal portfolio focused on data analytics, business intelligence, workflow automation, and applied AI.

The production-ready static website is in [`site-v2`](./site-v2). GitHub Pages deploys this folder through [`.github/workflows/publish.yaml`](./.github/workflows/publish.yaml).

## Local preview

Open `site-v2/index.html` directly in a browser, or serve the folder with any static web server.

## Stack

- Semantic HTML
- CSS
- Vanilla JavaScript
