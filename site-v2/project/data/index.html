SmartCine

Database design for cinema operations.

SQL · Relational modeling · Data analysis

GitHub ↗

Problem

Design a relational system that supports customer reservations, movie schedules, payments, and operational reporting for a fictional cinema.

Solution

The team implemented a MySQL-backed reservation application with a Python/Flask service and React interface. My documented contribution focused on database design and data analysis; Xiaoyang Fei focused on front-end and back-end system design and data collection.

Architecture and technology

The data model connects customers, movies, theaters, schedules, tickets, payments, and reviews. MySQL provides relational storage, while Python supports data processing and analytical queries.

Demonstration

The repository includes the entity-relationship model, SQL initialization, application code, sample data, notebooks, and project reports.

Limitations and next steps

The current repository requires security cleanup and a more reproducible setup before it should be treated as production-ready. Planned improvements include removing hard-coded credentials, hashing passwords, adding automated tests, and documenting analytical queries.
